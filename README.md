# Opportunity-hub
OportuniHub is a full-stack PHP + MySQL web app for posting and managing opportunities (jobs, internships, research). Includes authentication, role-based access (admin/contributor/visitor), CRUD features, subscriptions, and a complete front-end interface with database-backed storage and session handling. 
Team project developed with Carlos Forteza, Mario Rios, and Rosana Berrios, focusing on collaborative software development and shared implementation responsibilities.
